Image enhancement through morphing

2023 · classic computer vision · academic

Merge two images into one through a smooth intermediate sequence — the kind of computer vision that predates handing the problem to a neural net.

The problem that shaped it

Morphing is sensitive to noise. Blend two images where one carries noise and the artefacts show up throughout the transition, not just at the edges. So the work started with denoising, not with the morph itself — diagnosing an input-quality problem before treating it as an algorithm problem.

Pipeline

Gaussian blur via OpenCV smooths both source images before any blending happens. Alpha blending then starts at 0 and increments each iteration until the transition completes, producing a sequence of intermediate frames — stored as PNGs, then assembled into a GIF with RGB conversion applied so colour survives the encoding.

What the comparison showed

Tested with a five-step morph on noisy source images, and separately on human faces. Before-and-after comparisons made the denoising step's effect visible directly — the difference between an artefact-ridden blend and a clean one. No quantitative image-quality metric was computed; the evaluation was visual, and that's an honest limitation, not a hidden one.
