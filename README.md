# faisalalmuhaini.com

Personal portfolio site: projects, credentials and contact details.

Live: https://faisalalmuhaini.com

## Stack
Plain HTML, CSS and vanilla JavaScript. No framework, no build step.
Hosted on GitHub Pages with a custom domain.

## Structure
- `index.html`, `style.css`, `app.js`: main page and styles
- `case-*.html`: one page per project case study
- `images/`: project images and credentials
- `files/`: résumé and case-study PDFs

## Run locally
Open `index.html` in a browser. There is nothing to install.
