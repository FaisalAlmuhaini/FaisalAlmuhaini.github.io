2P — AI Engineer

Nov 2025 — present · computer vision · infrastructure · professional

Current role, on a large-scale public-safety operations deployment. The work sits at the join between AI and IT infrastructure — building the model-driven parts of the system and keeping the surrounding Windows and network environment running, in an environment with no internet access and version constraints that don't move on their own schedule.

Camera cleanliness monitoring

The strongest technical work in this role: detecting degraded camera feeds across a large deployment and turning a model score into something an operator can act on, running end to end on an offline inference server. Full write-up in work.

Asset tracking, self-hosted

Deployed Snipe-IT locally on Windows to get a working asset-tracking system in place — XAMPP, Apache, PHP, Composer, and MySQL, with Laravel underneath. Getting there meant working through a real chain of deployment failures: Composer dependency mismatches, missing PHP extensions, OpenSSL and libcurl.dll issues, Apache not starting, an incomplete .env, an invalid Laravel cipher, MySQL permission errors, and migrations that didn't apply cleanly the first time. The deployment is complete and functional for local asset tracking.

Device and endpoint management

Kaspersky Security Center work — endpoint and network-agent deployment, remote commands, time synchronisation, silent installation, device inventory, and Windows service troubleshooting. Any rollout follows the same shape regardless of the task: confirm the requirement, build a non-destructive test, run it on one device, capture logs and exit codes, pilot a small group, define a rollback before going further, deploy in stages, verify centrally, and document exceptions. Internal inventories and security-policy detail stay off this page by design.

A secure QR asset-lookup concept

A proposal, not a shipped system: attach a unique QR code to every physical asset so an authorised user or device can view current information, with unauthorised access hitting a controlled denial page instead. The design principles — opaque non-sequential identifiers, HTTPS only, least privilege and rate limiting, no confidential detail embedded in the code itself — are worked out. Implementation is not.
