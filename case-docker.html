Ticket classifier, containerised

2026 · practice project

A deliberately small end-to-end service — model, prediction API, health check, automated tests, Dockerfile, README and handoff notes — built to put container fundamentals into practice rather than leave them at certificate level.

It builds and it runs. It is not a production system and I don't present it as one.

Why this one exists

I'd finished a containers certification and wanted the muscle memory a course doesn't give you — writing a Dockerfile that actually builds, wiring a health check a container orchestrator can poll, and packaging a model so the API around it, not just the notebook, is the deliverable.

Built with

Docker · FastAPI · scikit-learn
